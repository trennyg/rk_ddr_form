## DRAFT SYSTEM

### Storage
- **Cloud:** `drafts` table on server (key, name, app_name, bank, saved_at, vals, drive_files)
- **Local:** `localStorage` keys `rka_draft_<key>` + index at `rka_draft_index`
- **`_draftsCache`:** module-level array, populated by `fetchDrafts()`. Used by `filterDrafts()` for search — no network call on search, reads cache only.

### Key functions
```
fetchDrafts()        POST { action: 'getDrafts' } → merges cloud + local → sets _draftsCache
renderDraftList()    Calls fetchDrafts(), resets search box, shows prompt. Called on:
                       - DOMContentLoaded (page load)
                       - switchTab(10) — Submit tab (added 4 July 2026)
                       - buildUploadSummary() — via switchTab(9)
                       - deleteDraft() — after deletion
                       - saveDraftNow() — after manual save
filterDrafts(query)  Reads _draftsCache only — NO network fetch. Called on search input.
saveDraft(appName)   Upserts cloud + local. Non-fatal — fails silently.
deleteDraft(key)     Removes cloud + local, then calls renderDraftList().
openDraft(key)       POST { action: 'getDraft' } → restores form fields.
```

### Draft vals format
Flat `{ fieldId: value }` object — DOM element IDs as keys. Key special entries:
- `__numCoApps` — string integer, sets number of co-app blocks on restore
- `f_exec_residence`, `f_exec_office`, `f_exec_asset` — SELECT values; if "Other", companion `_other` field holds the text

### Autosave
`scheduleAutosave()` fires on every `change`/`input` event (DOM-wide). 2-second debounce.
Gate (added 4 July 2026): fires only if at least one of `f_app_name`, `f_bank`, `f_app_mobile`, `f_app_kyc_pan_no` is non-empty — prevents blank-name draft creation on a fresh/cleared form.
`beforeunload` beacon: `navigator.sendBeacon` with `{ type: 'text/plain' }` Blob.
Tab-switch save: `saveDraft()` called directly in `switchTab()` — immediate, not debounced.

## FORM SUBMISSION

All submissions are **final** — intermediate-save path was removed 3 July 2026.
`row[2]` is hardcoded `'Yes'` (was `submitType === 'final' ? 'Yes' : 'No'`).
`buildRow()` produces a 410-element positional array → POST `body.row` to backend.
`case_session_id` sent as `body.case_session_id` (UUID from `currentCaseId`).
Duplicate check: backend returns `{ status: 'possible_duplicate' }` → modal asks exec to confirm new visit or resubmit.

## EXEC DROPDOWNS (Tab 3)

Three separate SELECT fields: `f_exec_residence`, `f_exec_office`, `f_exec_asset`.
Each has a companion `_other` text input (shown when "Other" selected).
`handleExecNameChange(sel)` derives other-input ID as `sel.id + '_other'`.
`NONE_APPLICANT_PROVIDED` sentinel = exec was not present for that verification type.
`row[141]` = resolved residence exec, `row[408]` = office exec, `row[409]` = asset exec.

## PAYSLIP OCR

`extractPayslipNetPayJS()` and `parseWordsINR()` — DO NOT modify priority order.
"In words" line = primary. Arithmetic fallback (gross − deductions) = last resort only.
`directNet` always takes priority over arithmetic.

## KNOWN QUIRKS

- **`filterDrafts()` never fetches** — it reads `_draftsCache` only. If the cache is stale (e.g. another session saved a draft), the exec won't see it until `renderDraftList()` is called. As of 4 July 2026, switching to tab 10 now triggers `renderDraftList()` to address this.
- **`_draftsCache` updated locally on save** — `saveDraft()` updates `_draftsCache` in-place (lines ~5660–5661) without a full refetch, so the draft list stays consistent after autosave without a round-trip.
- **Drive file keys** — `uploadedFiles` uses form field IDs as keys. Draft restore uses `_draftDriveFiles` for Drive-hosted photos and `_discardedDriveKeys` to track which were intentionally removed by the exec.
- **ITR section rebuilt on tab switch** — `buildItrSection()` (called on `switchTab(5)`) rebuilds ITR/F16 inputs from `itrStore` to handle co-app count changes without losing entered values.
- **BSA/DSA form modes** — tabs 3, 6, 7, 8 are hidden for BSA/DSA modes via `HIDDEN_BSA_DSA` set in `switchTab()`.
- **PDF scale** — OCR PDF rendering uses scale 3.5 (252 DPI), PNG format. Do not reduce.
